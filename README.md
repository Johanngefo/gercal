# vault-calendar-Dates
Obsidian Plugin. Reads dates (DD.MM.YYYY) in your Notes and adds them to a calender. 

Mark Birthdays with DD.MM.YYYY(G). Color: Pink </br>
Mark Appointments with DD.MM.YYYY(T). Color: Green</br>
Mark Important with DD.MM.YYYY(W). Color: Red</br>
Mark As of DD.MM.YYYY(S). Color: Grey</br>
Or do not mark. Color: Magenta
