# vault-calendar
Obsidian Plugin. Reads dates (DD.MM.YYYY) in your Notes and adds them to a calender. 

Mark Birthdays with DD.MM.YYYY(G). Color: Pink
Mark Appointments with DD.MM.YYYY(T). Color: Green
Mark Important with DD.MM.YYYY(W). Color: Red
Mark As of DD.MM.YYYY(S). Color: Grey
Or do not mark. Color: Magenta
